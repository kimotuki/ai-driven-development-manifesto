# AI駆動開発マニフェスト (AI-Driven Development Manifesto)

[English](#english)

「AI駆動開発マニフェスト」の原文を管理するリポジトリです。

マニフェスト本体は技術が変わっても変わらない原則と価値観を、実践ガイドはその時点での具体的なツールや手法を扱います。実践ガイドはマニフェストより頻繁に更新します。

- 本文（日本語）: [MANIFESTO.md](./MANIFESTO.md)
- 本文（English）: [MANIFESTO.en.md](./MANIFESTO.en.md)
- 実践ガイド（日本語）: [PRACTICES.md](./PRACTICES.md)
- 実践ガイド（English）: [PRACTICES.en.md](./PRACTICES.en.md)
- 公開ページ: https://www.ai-driven.dev/ai%E9%A7%86%E5%8B%95%E9%96%8B%E7%99%BA%E3%83%9E%E3%83%8B%E3%83%95%E3%82%A7%E3%82%B9%E3%83%88/
- 更新履歴: [CHANGELOG.md](./CHANGELOG.md)

## 更新の流れ

1. `main` から作業ブランチを作成する
2. 日本語版（`MANIFESTO.md`・`PRACTICES.md`、正）と英語版（`MANIFESTO.en.md`・`PRACTICES.en.md`）を同じPRで編集し、`CHANGELOG.md` の「Unreleased」に変更点を追記する
3. Pull Request を作成し、レビューを受けてマージする
4. 区切りのよいタイミングでバージョンタグ（例: `v1.1.0`）を付け、公開ページに反映する

詳しくは [CONTRIBUTING.md](./CONTRIBUTING.md) を参照してください。

## English

This repository manages the original text of the "AI-Driven Development Manifesto."

The manifesto covers principles and values that hold as technology changes; the practice guide covers the specific tools and methods of the moment and is updated more often.

- Japanese (authoritative): [MANIFESTO.md](./MANIFESTO.md)
- English translation: [MANIFESTO.en.md](./MANIFESTO.en.md)
- Practice guide: [PRACTICES.en.md](./PRACTICES.en.md) (Japanese: [PRACTICES.md](./PRACTICES.md))
- Changelog: [CHANGELOG.md](./CHANGELOG.md)

All changes are made through pull requests. When the Japanese text changes, update the English translation in the same pull request.
